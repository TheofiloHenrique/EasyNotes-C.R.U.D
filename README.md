# 📝 EasyNotes!

Un CRUD sencillo para crear y administrar notas.

Este proyecto fue realizado como una actividad de la universidad. La idea era hacer un CRUD bastante simple como trabajo extra para obtener una nota adicional.

Sirvió para practicar un poco el uso de **Express**, bases de datos y la creación de una aplicación CRUD.

## 🚀 Funcionalidades

Con EasyNotes puedes:

* Crear notas
* Ver las notas
* Editar notas
* Eliminar notas

## 🛠️ Tecnologías utilizadas

* **Node.js**
* **Express**
* **Better-SQLite3**
* **Bootstrap**

## 💻 Ejecutar el proyecto

Después de instalar las dependencias, simplemente ejecuta:

```bash
npm run dev
```

Y listo. La aplicación se iniciará en modo desarrollo.
